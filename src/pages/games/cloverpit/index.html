How to Speed Up Animations in Cloverpit

  1. Open Steam, right-click Cloverpit, and select Manage > Browse local files.
  2. Navigate to the SaveData\SettingsData\ folder.
  3. Open SettingsDataFull.json in a text editor (like Notepad).
  4. Scroll to the bottom and locate the line that says: "transitionSpeed": #
  5. Change the # to your desired value. (I set mine to 20)
  6. Save the file and launch the game.
